# 놀이기구 안전관리 시스템 (스마트 바이킹)

2026학년도 2학기 마이크로프로세서(캡스톤디자인) 조별과제

아두이노로 바이킹(Pirate Ship) 놀이기구 모형을 움직이고, 기울기·모터 온도를 감시해서 위험할 때 스스로 멈추는 안전관리 시스템입니다.

![완성된 바이킹 모형](images/model.jpg)

## 주요 기능

- **START 버튼**: 누르면 부저가 3초 동안 울리고 카운트다운 후 운행 시작
- **바이킹 왕복 운동**: N20 모터가 일정 시간마다 방향을 바꿔 배를 앞뒤로 흔듦
- **리니어 액추에이터**: 버튼을 누르는 동안 상승, 놓으면 하강
- **비상정지**: 비상 버튼, 30° 이상 기울기, 모터 과열 시 모든 모터 즉시 정지
- **LCD 표시**: 운행 상태, 모터 온도, 기울기, 정지 원인 표시
- **베어링 구조**: 일반 바이킹과 달리 베어링을 중앙이 아닌 양쪽 다리에 설치해서 무게를 나누고 교체를 쉽게 함

![양쪽 다리에 설치한 베어링](images/bearing_top.jpg)

## 사용 부품

| 부품 | 역할 |
|---|---|
| Arduino Uno | 전체 제어 |
| L298N 모터 드라이버 | 모터 2개 방향·속도 제어 |
| N20 DC 모터 (12V) | 바이킹 배 구동 |
| 리니어 액추에이터 (12V) | 상하 구동 |
| MPU6050 | 기울기, 진동, 온도 측정 (I2C) |
| LCD 1602 (I2C) | 상태 표시 |
| 택트 스위치 4개, 부저 | 조작, 경고음 |
| 12V 어댑터 | 모터 전원 |

## 핀 연결

| 아두이노 | 연결 |
|---|---|
| D2 | 액추에이터 버튼 |
| D3 | 바이킹 모터 버튼 |
| D4 | 비상정지 버튼 |
| D12 | START 버튼 |
| D9 | 부저 |
| D5 / D7 / D8 | L298N ENA / IN1 / IN2 (액추에이터) |
| D6 / D10 / D11 | L298N ENB / IN3 / IN4 (N20 모터) |
| A4 / A5 | SDA / SCL (LCD 0x27, MPU6050 0x68) |
| D13 | 비상 상태 표시 LED |

버튼은 내부 풀업을 사용해서 저항 없이 GND에 연결합니다. 12V는 L298N에만 연결하고, 모든 GND는 공통으로 연결합니다.

```

```

## 사용 라이브러리

- `LiquidCrystal I2C` (Frank de Brabander)
- `Wire` (아두이노 기본)

## 문제 해결 기록

1. **TB6612FNG 드라이버로 모터가 움직이지 않음** → 모터를 전원에 직접 연결해서 모터는 정상임을 확인, L298N 드라이버로 교체
2. **LCD와 MPU6050이 모두 인식되지 않음** → 진단 코드로 A0~A5 핀이 모두 LOW인 것을 확인, 아두이노 아날로그 핀 손상으로 판단해서 보드 교체
3. **MPU6050 위치** → 움직이는 배에 붙이면 선이 꼬이고 기울기를 잘못 판단해서, 고정된 모터 하우징에 부착
